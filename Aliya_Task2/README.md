This is a personal portfolio website I created as part of my Oasis Infobyte Web Development Internship. It gives a short introduction about me and shows my skills and projects.

## Objective
The main aim of this project is to create a personal website using HTML, CSS, and JavaScript.

## Technologies Used

- CSS
- JavaScript

## Features
- Personal introduction
- Skills and projects section
- Contact details
- Simple and attractive design

## Files Used

- `style.css` – Used to design and style the website.
- `script.js` – Used for JavaScript functions.

## Conclusion
This project helped me understand how to create a personal portfolio website and improve my web development skills.
