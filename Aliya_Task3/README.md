# Temperature Converter

## About the Project
This is a temperature converter website I created as part of my Oasis Infobyte Web Development Internship. It helps users convert temperatures from one unit to another.

## Objective
The aim of this project is to make a simple website that converts temperature values using HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Converts temperature values between different units.
- Simple and easy-to-use interface.
- Displays the converted temperature.
- Uses a responsive layout.

## Files Used
- `index.html` – Contains the structure of the website.
- `style.css` – Adds colors, design, and layout.
- `script.js` – Performs the temperature conversion.

## Conclusion
Through this project, I learned how to use JavaScript for calculations and how HTML and CSS work together to create a website.
